# 📊 Plotting & Data Analysis Repository

A comprehensive collection of data visualization, exploratory data analysis (EDA), and machine learning projects focused on FIFA player statistics and other datasets.

## 🎯 Project Overview

This repository contains multiple analysis notebooks covering:
- **FIFA Player Analysis** (2017-2023): Comprehensive EDA and wage prediction modeling
- **Advanced Plotting Techniques**: Interactive visualizations, density plots, contour analysis
- **Data Cleaning & Preprocessing**: Handling missing values, feature engineering
- **Machine Learning Models**: Predictive modeling for FIFA player wages

## 📁 Repository Structure

```
├── eda/                          # FIFA dataset exploratory data analysis (2017-2023)
│   ├── eda17.ipynb - eda23.ipynb # Year-specific FIFA analysis
├── final_steps/                  # Final EDA and ML models
│   ├── eda.ipynb                 # Comprehensive EDA
│   └── model.ipynb               # ML wage prediction models
├── fifa_dataset/                 # Raw FIFA data (2017-2023)
├── fifa_dataset_cleaned/         # Cleaned & processed FIFA data
├── Interactive Controls/         # Interactive visualization demos
└── requirements.txt              # Python dependencies
```

## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:
```bash
git clone https://github.com/N1KH1LT0X1N/Plotting.git
cd Plotting
```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Launch Jupyter:
```bash
jupyter notebook
```

## 📊 Key Features

### FIFA Player Analysis
- **Multi-year dataset**: FIFA 17-23 official player data
- **60+ features** per player including ratings, wages, physical attributes
- **100K+ player records** across 6 years
- **Wage prediction models**: Random Forest, Linear Regression, Gradient Boosting

### Visualizations
- Interactive Plotly dashboards
- Geographic wage distribution maps
- Correlation heatmaps
- Temporal trend analysis
- Position-wise performance metrics

### Data Cleaning Pipeline
- Missing value imputation (KNN, median)
- Outlier detection and handling
- Feature engineering (age categories, potential gap, composites)
- Body type extraction and normalization

## 🛠️ Technologies Used

- **Data Analysis**: Pandas, NumPy, Polars
- **Visualization**: Matplotlib, Seaborn, Plotly
- **Machine Learning**: Scikit-learn, XGBoost
- **Statistical Analysis**: SciPy, Skimpy
